# 2026-09-17

## 新增互动演示：日食与月食（`/demos/eclipses`）

在 `frontend/src/features/demos/scenes/eclipse/` 下新建了独立演示，日食与月食共用一套日—地—月系统。

**共享外壳的最小扩展（通用，非日食专用）**
- `types.ts`：新增 `DemoSceneState = object`、`DemoSceneOptions.onState`、`DemoScene.runCommand(command: unknown)`。
- `registry.ts`：`DemoDefinition.controlPanel?: () => Promise<{ default: Component }>`，可懒加载的自定义控制面板。
- `DemoDetailView.vue`：加载 controlPanel 组件，把 `sceneState` 与 `sendCommand` 透传给它。**没有按 slug 分支**，也不读 state 内容。
- 场景与面板之间用 `scenes/eclipse/types.ts` 里的 `EclipseSceneState` / `EclipseCommand` 强类型通道；`isEclipseCommand` 在场景侧收窄。

**分层**
- 真实量：`ephemeris.ts`（astronomy-engine 封装）+ `geometry.ts`（纯函数）。所有时刻、峰值地点、接触时刻、角直径、遮挡比例都来自这里。
- 示意量：`config.ts` 的 `DISPLAY_*`。仅决定画多大，界面明确标注“示意比例，非真实尺度”。
- 影锥用 `displayShadowCone` 做「半径按天体显示半径缩放、长度按距离压缩缩放」的双轴映射，因此本影在真实位置闭合——环食时落点处本影半径为负、伪本影接管。

**复用**：`engine/stage.ts`、`engine/glow.ts`、`engine/starfield.ts`；`createEarthGlobe` 从 `scenes/meteor-shower/earth.ts` 移到 `engine/earthGlobe.ts` 供两个演示共用；纹理仍指向 `demos/meteor-shower/earth-day.jpg` 与 `demos/moon/moon-color-4k.webp`，未复制。

**验证**：vue-tsc 干净；vitest 39 文件 328 用例全过（新增 eclipse 相关 62 例）；vite build 成功。

**环境注意（重要）**
- `yarn` 在本机不可用（corepack 的 yarn.js 缺失）。改用 `node node_modules/vitest/vitest.mjs run`、`node node_modules/vue-tsc/bin/vue-tsc.js`、`node node_modules/vite/bin/vite.js build`。
- `vite build` 直接跑会被沙箱的批量删除守卫拦下（它会清空 `dist/assets` 的 72 个文件）。用 `--outDir dist/check` 绕过。
- 无头浏览器验证：`chrome --headless=new --enable-unsafe-swiftshader --use-angle=swiftshader --dump-dom <url>`，WebGL 在 SwiftShader 下可用。
- 截图要**去掉 `--disable-gpu`**，否则 WebGL 图层不会合成进 `--screenshot`（DOM 正常、3D 全黑）。Chrome 是原生 exe，`--screenshot=/tmp/x.png` 会写到 `C:\tmp\x.png` 而不是 MSYS 的 /tmp，要用 Windows 路径并去 `C:/tmp` 找。
- 用 `(vite ... &)` 起的 dev server 会在工具调用结束时被杀，需要「起服务 + 用服务」放在同一条命令里。

## 收尾（2026-09-18 凌晨）

用无头 Chrome 截图逐一核对了真实观感，并据此做了两处调整：
- `DISPLAY_SUN_DISTANCE` 8 → 7、`cameraFramingFill` 0.86 → 0.94：默认取景更紧，地球直径从约 87px 提到 130px 以上，日—地—月与影锥一眼可读。
- 标签锚点改为天体**顶部**（`anchorAbove`），此前「太阳」标签压在明亮日面上不可读；「月球轨道面」标签从轨道面圆心（即地球所在处）移到盘面边缘。
- 截图确认：月全食时「月面进入本影 100%」、月面呈克制铜红；日环食时「伪本影」标签与伪本影锥出现，落点处本影半径为负——几何与观测自洽。
