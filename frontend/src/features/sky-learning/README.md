# 星空记忆：免登录全天课程

入口 `/learn/sky`，主导航为“星空记忆”。不依赖身份服务、学习服务或星表 API；个人记录只写入当前源的 IndexedDB。

中国星宫路线入口 `/learn/chinese`：41 课、7 个阶段，按入门、三垣、四象二十八宿、代表星官排列。目录单独编号与统计，传统连线和名称按课程切换；同一颗星共享复习卡和本地档案。详细范围与依据见 `docs/chinese-sky-learning.md`。

## 已实现

- 104 节中文课程、18 个阶段，覆盖全天 88 星座及 43 颗目标恒星的定位/名称练习。前 19 课保留核心路线与稳定 ID；后续按四季连通、第二轮星名、34 个邻区星座、33 个南天星座及综合回顾排列。
- 长蛇拆成两课、巨蛇头尾分开两课、波江拆成三课，以共享端点衔接；较暗星座先认形和邻区，不强加大量星名。单节名称练习最多 3 颗目标；图形导读不冒充认形测试。
- 目录可按阶段筛选、按课号或星座/目标星名及别名搜索，筛选后保留原课号。每章显示学习目的，初学者可顺序学，也可任选后续课程。
- 首页提供继续学习/推荐课程与到期复习入口。目录配有阶段快捷导航、完成进度及“全部 / 未完成 / 已完成”组合筛选；每课的缩略图使用该课真实星位与连线投影，帮助辨认星形。
- 学习页显示观察、回忆、完成三个步骤及已作答进度；完成后可直接进入同一路线的下一课。图形导读只显示观察与完成两步。星区观察窗提供模式切换、辅助状态、目标图例与键盘提示，并适配手机宽度和明暗主题。
- 课程目录显示课号，可以直接选择任意课程；同一未完成学习课程续学，其他课程从导读开始。切课保留已保存的作答、复习卡和完成记录，不保留多份进行中会话；“继续上次学习”单独进入当前会话。
- 图形导读、主要星名/连线开关、朝向切换；导读完成只计学习过，不产生虚假的测验成绩。
- 名称定位与星点名称回忆，精确物理 ID 判分，接受经过内容数据配置的中文/西文别名。
- 静态 ICRS 教学星图：真实星表位置与星等、球面立体投影、本课连线、周围亮星。不是实时地平星图；通过页面链接进入现有完整星图进行实际时地探索。
- 自然星点：根据星等统一压缩显示亮度，渐变亮核与弱光晕代替实心圆盘；使用星表 B−V 色指数并降低饱和度。暗星变淡且无额外光晕，透明点击区与视觉大小分离。画面是适合学习的显示近似，并非校准过的人眼/光害模拟。
- 星图上方可随时切换“自然星空 / 清晰认星”：清晰模式使用接近原版的较大亮点与更明显的辅助线。两种模式共用星位、命中范围和名称隐藏规则；偏好独立保存在当前浏览器 localStorage，不计为答案提示，不改变学习进度。存储不可用时仍可在当前视图切换。
- 答题反馈、课程进度、到期复习与刷新续学。提示、反馈及近期答案曝光保守标记，不把刚见过答案的成功当成独立回忆。
- 当前复习阶梯为 1/3/7/14/30 天，错误/提示题 10 分钟后重学；这是初版规则，不是 FSRS 或经校准的记忆概率。30 分钟曝光窗口也是设计参数。
- 事务保存、版本冲突检测、唯一作答 ID 去重；Web Locks 保证同一源只有一个学习页面可以写入，其他页面只读。需要 HTTPS 或 localhost。
- 完整 JSON 备份、大小/版本/数据一致性校验、预览确认后整体替换。导入保留原始答题/到期时间，取消旧的进行中会话。无效备份不能覆盖记录。

## 模块

- `content.ts`：核心课程、章节顺序与星野装配。新课程按所需星点的球面平均位置自动取中心，兼容跨赤经零点与南北极区。
- `extensionLessons.ts`：四季连通、第二轮星名与综合回顾；`neighborLessons.ts`：邻区 38 课；`southernLessons.ts`：南天 33 课。星座连线/背景星来自打包数据。
- `chineseLessons.ts`：中国星宫 41 课；`ChineseSkyOverview.vue`：三垣、四象与各宿的直接选课入口。`content.ts` 保留原 `lessons` 导出，并使用 `allLessons` 校验两条路线的会话与存档。
- `learning-stars.json`：从仓库现有星表、文化包提取的子集，带源版本、归属与许可信息。
- `projection.ts` / `LearningStarChart.vue`：球面投影、可访问交互；测验不渲染星名或别名，鼠标按最近星点判定，键盘使用中性编号。
- `LessonPreview.vue`：课程目录与推荐区的只读真实星形预览；`learning-page.css` / `chinese-overview.css`：学习页与中国星宫索引的响应式样式。
- `starAppearance.ts`：跨课程统一的星等/色指数显示响应，独立于当前题目、标签和选中状态；各星的渐变定义使用组件独立 ID。
- `session.ts`：题目编排、别名判断、复习筛选、曝光记录和内容引用校验。
- `repository.ts`：IndexedDB、复习调度、备份验证。事件、卡片、检查点在一次比较版本的事务中写入，成功后才更新界面。
- `../../views/SkyLearningView.vue`：目录、学习/复习会话、本地进度和备份管理。

数据重建：在仓库任意目录运行 `node tools/catalog/build-learning-content.mjs`（路径需相对当前目录调整）；脚本使用仓库内发布星表，不抓取新外部数据。前端数据子集公开，可从页面“星图数据与来源”查看归属。

## 验证

前端目录运行 `yarn test:run src/features/sky-learning`；全量类型与生产构建运行 `yarn build`。注意旧 `yarn typecheck` 命令使用根 tsconfig 的空入口，不能代替 project-reference 构建检查。

测试覆盖真实目录坐标、88 星座顺序、首轮及扩展星名身份、所有新增课程的投影范围与存档恢复、原 19 课兼容性、阶段筛选和搜索、极区/赤经跨零投影、标签隐藏、别名、调度、重复提交、备份完整性、提示跨目标传播、失败后重试，以及页面只读状态。存储纯逻辑与组件测试不假装模拟原生 IndexedDB；浏览器验收实际确认保存、刷新反馈续学、双页锁定/接续、导出恢复、无效版本拒绝和到期复习。
