# 今晚看什么

入口 `/tonight`。免登录，复用星图的版本化星表、文化数据和 Astronomy Engine 2.1.19，在模块 Worker 中计算。首版提供晴空、无遮挡前提下的裸眼观测建议；没有天气 API、实测光污染或设备性能模型。

## 数据与计算

- `solarTimeline.ts`：为月球与七颗行星计算地平线上方的连续时段和真实升落事件；日暮背景按太阳几何高度 0°、−6°、−12°、−18° 分段。通常显示当地 16:00 至次日 08:00，选定窗口超出时扩展至对应的中午边界，避免截掉极夜或自定义观测时段；时间跨度保留 DST 的实际长度。
- `nightWindow.ts`：观测地 IANA 时区、当地夜晚归属、用户时段与日月/暮光事件。内部为 UTC，跨午夜保持日期；不能用浏览器时区替代观测地时区。
- `candidates.ts`：月球、水金火木土、至多 70 颗亮星、17 个主要星座图形及现有大三角星群。星座使用人工挑选的物理 HIP 骨架及必要锚点，不代表整个 IAU 天区的可见性。文化和星名来源继续沿用仓库的第三方声明。
- `engine.ts`：通过共享 `SkyCoordinateSampler` 获取无过滤的站心太阳系坐标和恒星位置，按一分钟采样；每 15 个采样点让出 Worker 事件循环并检查取消。五分钟以下窗口不推荐，5–20 分钟窗口保留限制说明，精选要求至少 20 分钟。
- `visibility.ts`：按目标类别设置太阳暗度/高度条件，星座同时检查必要锚点和至少 80% 核心成员。环境档位、月光、低空影响使用保守启发式，不是肉眼可见概率或经校准的极限星等。
- `ranking.ts`：按高度、辨认条件、窗口时长与观赏价值评分；精选为不同类别保留机会并减少核心成员重复。窗口分数使用区间平均特征，最佳时刻在该区间中选择。
- 原因和限制携带事实字段与时间锚点，页面生成中英文说明。最佳时刻的高度不等同于全天最高高度；星座卡片方向参考锚星，骨架高度评价参考必要锚点。
- `SkyMapWorkerClient.planTonight`：复用完整性校验后的星表。后续请求会使旧规划在批次边界停止。每页销毁自己的 Worker，避免留存后台计算。
- `session.ts`：在本次页面会话中保留成功计算的地点、日期和条件，进入星图再返回可恢复；刷新页面重置，不将坐标写入持久存储。星图链接保留精确 UTC 时刻，异地观测同时显示观测地时区与设备时间输入的区别。

## 页面与太阳系时间轴

保留原有标题、观测设置、夜晚概览、精选推荐与分类卡片（含高度曲线、推荐原因和星图入口）。仅太阳系面板参考 Stellarium 的横向时段表示方式，采用本站蓝金配色、圆角面板和柔和的昼暮背景，不复刻其整页日历布局。默认整夜，淡色条表示地平线上方，亮色条表示满足当前观测条件的推荐时段，二者不能混用。天王星与海王星展示升落并标明需要光学器材，不进入裸眼推荐。点击太阳系行在原位置展开依据、注意事项和星图链接。不展示没有数据支持的卫星过境或活动。

## 验证

在 `frontend` 运行 `yarn test:run src/features/tonight src/features/sky-map`，生产验证使用 `yarn build`（包含 `vue-tsc -b`）。

`engine.test.ts` 包含固定的 NASA/JPL Horizons DE441 站心方位/高度参考：2026-10-27 12:00 UTC，114.0579°E、22.5431°N、海拔 0.020 km，quantity 4，AIRLESS，无大气折射。太阳、月球、木星和土星采用独立保存的数值，验证方向角距小于 0.1°，不以同一个天文库动态生成期望值。查询说明：https://ssd-api.jpl.nasa.gov/doc/horizons.html 。

测试还覆盖真实发布星表、推荐窗口与星图一致、月落后解除月光处罚、极昼空结果、分离窗口、骨架身份和计算取消。日期、观测时区与系统时间分别处理；自定义时间遇到 DST 重复/缺失时明确报错。

浏览器验收覆盖深圳与纽约的观测时间、土星/飞马座/夏季大三角的自动选中、返回后恢复条件、倒序时段报错，以及 390px 手机视口无横向溢出。首版不联网获取天气，定位仅在用户点击按钮后由浏览器申请授权。

后续扩展：逐小时天气融合、中国星官推荐内容、器材能力模型和观测记录。相关设计见 `docs/tonight-observing-plan.md`。
