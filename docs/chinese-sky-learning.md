# 中国星宫学习

入口 `/learn/chinese`，也可从“星空记忆”页面的“中国星宫”标签进入。无需登录，沿用本地学习档案、备份与复习流程。

## 学习顺序

共 41 课，独立编号；全部开放，可按顺序学习，也可直接选择某课或总览中的某一宿。

| 课号 | 阶段 | 学习目的 |
| --- | --- | --- |
| 1–2 | 读懂中国星空 | 以北斗为入口，区分星官、星名、三垣和二十八宿 |
| 3–8 | 三垣 | 依次认识紫微、太微、天市的垣墙和代表星官 |
| 9–15 | 东方青龙 | 角、亢、氐、房、心、尾、箕 |
| 16–22 | 北方玄武 | 斗、牛、女、虚、危、室、壁 |
| 23–29 | 西方白虎 | 奎、娄、胃、昴、毕、觜、参 |
| 30–36 | 南方朱雀 | 井、鬼、柳、星、张、翼、轸 |
| 37–41 | 代表星官 | 从织女、河鼓、天津、五车等熟悉亮星回看传统星官 |

每课先观察实际恒星位置和传统连线，可切换自然星空/清晰认星、开关辅助线和名称、改变朝向。名称课每次最多引入三颗星，随后隐藏名称练习定位与回忆；图形导读完成只表示学习过，不计作独立认形测验。

## 内容边界

- 三垣是紫微垣、太微垣、天市垣。紫微垣在北天极附近，另两垣不能一概解释为绕极天区。
- 四象各含七宿；目录按传统顺序排列，不表示四象在任意时刻分别处于地面观测者的东、北、西、南方向。
- “宿”读 xiù。“二十八宿天区”与“二十八个同名星官”不是同一个层级；课程以同名星官帮助辨认和记忆，没有用这些连线冒充整宿边界。
- 牛宿星官不等于河鼓星官；俗称牛郎星的是河鼓二。河鼓位于牛宿天区，不能把这两个层级混在一起。
- 当前课程是入门选集，不覆盖中国传统文化包的全部星官。神话和宫廷等象征用于介绍文化命名，不用于占卜或预测。
- 恒星使用现代星表坐标及各星目录历元，未将星位回推至古代。岁差会改变天极相对恒星的位置，不能把今天的北极星关系直接套到所有古代时期。

## 名称、复习与存档

两条路线各有课号和完成计数，原 104 课 ID 保持稳定。中国课程优先显示 `traditionalName`；例如同一个 HIP:11767 在中国课程显示“勾陈一”，在原路线显示“北极星”。原名及已收录的别名仍接受为答案，因此当前名称练习检验恒星识别，不是严格限定某一历史称谓的考试。

同一颗物理恒星的定位/名称复习卡继续使用 `HIP:编号:locate|name`，两条路线共享到期时间。复习使用最近一次练习该卡的课程与相应名称。答案曝光也跨路线记录，不把刚看过另一路线答案的作答当成独立回忆。

备份覆盖两条路线，导入整体替换；清除记录也覆盖两条路线，界面明确说明。没有新增登录、服务器账号或个人数据上传。

## 数据与来源

- 恒星位置、星等与 B−V 色指数来自项目内 Hipparcos 等星表，必要的缺失星保留独立补充记录与来源。构建脚本校验每个连线端点都存在，不以虚拟星点补图。
- 传统名称与连线来自项目固定版本的 [Stellarium Chinese sky culture](https://github.com/Stellarium/stellarium-skycultures/tree/014fbb5e59233d133c22f9811af96b67d05a95c9/chinese)，上游注明以香港太空馆星图和伊世同《中西对照恒星图表（1950.0）》等为依据，许可为 CC-BY-SA（上游未指定版本）。不同文献和时代的星官划分可能不同。
- 入门顺序参考 [可观自然教育中心暨天文馆：三垣四象二十八宿](https://www.hokoon.edu.hk/weeklysp/1909_5.html)。教学描述与交互由本项目编写，未复制其图片或整段文章。

课程定义位于 `frontend/src/features/sky-learning/chineseLessons.ts`，总览组件为 `ChineseSkyOverview.vue`；传统星官数据由 `node tools/catalog/build-learning-content.mjs` 打包。前端无需运行星表后端即可学习。

## 验证

在 `frontend` 运行 `yarn test:run src/features/sky-learning` 和 `yarn build`。验证包括四象各七宿顺序、真实星官连线与目标身份、投影范围、全部课程的会话恢复、跨路线名称与进度、自由选课、刷新续学、答题时无名称泄露，以及原有课程和备份兼容性。
