## 1. 使用这份顺序的方式

默认面向中文、裸眼观星、北半球中纬度入门者。模拟星图可严格按下列主线学；实际户外学习将四季章节从当前可见的一章开始轮换。课程不能把北斗、仙后座或任何完整星座在某地某时的可见性当作固定前提。

**默认主线：读图基础 → 北方定向 → 冬季亮星 → 春季导航 → 夏季骨架 → 秋季星链 → 四季连通 → 主星名称第二遍 → 邻区补全 → 南天路线 → 全天综合 → 按兴趣学习编号与传统星官。**

学习终点分为三个层级：

| 层级 | 实际能力 | 大致覆盖 |
| --- | --- | --- |
| 日常认星 | 找到关键锚点，认识常见星空，主要星名能双向回忆 | 21 个核心星座、约 20 颗首轮亮星 |
| 区域熟练 | 能借熟悉锚点找到较暗邻区，形成连通的心中星图 | 扩展至 55 个星座的图上位置与代表结构 |
| 全天拓展 | 理解南北天空关系，在模拟图中定位全天星座 | 88 个星座；实地记录单独计算 |

55 个星座是本课程阶段性分组，不意味着北半球中纬度可完整看见它们。南方低空、被遮挡或永不升起的部分改用模拟场景。88 星座是可选的完整拓展终点，普通用户完成核心路线也可获得完整学习成果。

现代星座、星群、星团分开解释。IAU 的星座定义是天区；识别连线是教学辅助。[IAU 星座定义与列表](https://www.iau.org/IAU/IAU/Astronomy-FAQs/Constellations.aspx)。

## 2. 第 0 阶段：先学会读图，不背星名

建议 3–4 个短单元，顺序如下：

1. **地平线与天顶**：知道星图里哪些区域表示地平线、头顶和当前视野。
2. **方向和图表约定**：学会东南西北；认识当前产品使用的投影与朝向，不把屏幕左右永久当成东西。换到另一种星图时先读方向标记。
3. **亮度与图层**：理解星点大小通常编码视亮度；星座连线、名称和插图是辅助图层，真实天空没有这些线。
4. **时间变化**：拖动模拟时间，观察同一星形的朝向和位置变化；理解行星会改变相对恒星的位置，不把一个临时亮点误作固定骨架成员。

此时不要求背赤经赤纬、距离、光谱或全部希腊字母。开始训练前先让用户完成点击星点、缩放、撤销和主动查看提示的练习。

达标：能把一张星图对应到某个观察方向，知道如何找到亮星，并能在两种有效时间场景中认出同一个简单图形。

## 3. 第 1 阶段：建立北方方向感

| 顺序 | 内容 | 首次记忆任务 |
| --- | --- | --- |
| 1 | 北斗七星的勺形 | 分清斗身四星与斗柄三星，先选对七个点 |
| 2 | 斗口两星 | 记天璇、天枢的位置；练习从天璇朝天枢方向寻找北极星 |
| 3 | 北极星 | 记“北极星／勾陈一”，知道它是方向锚点 |
| 4 | 小熊座 | 记北极星位于小熊座，先辨认可见的主要结构 |
| 5 | 仙后座 | 记 W／M 形；旋转朝向后仍能识别 |
| 6 | 大熊座与北斗的关系 | 知道北斗是大熊座中的熟悉星群，初步扩展到更大的图形 |
| 7 | 北方小测 | 无名称找出北斗、北极星和仙后座，并说明相对方向 |

首轮星名：北极星、天璇、天枢。北斗其余五颗星的名字放到第二遍，避免一开始记七个名字和七个位置。

北极星接近北天极，并不是全天最亮恒星；北斗斗口两星可以帮助寻找它。[NASA 北极星教程](https://science.nasa.gov/solar-system/skywatching/what-is-the-north-star-and-how-do-you-find-it/)。

达标：从无名称的北方星图找到方向锚点，在至少两种朝向下完成；较暗的小熊成员在模拟图练习即可。仙王、天龙的完整形状留到邻区拓展。

累计核心星座：大熊、小熊、仙后，共 3 个。

## 4. 第 2 阶段：用冬季亮星建立第一张“大地图”

冬季主干适合模拟课程早期学习，因为有多颗亮星、鲜明图形和重复利用的导航关系。户外可根据季节调整章节先后。

| 顺序 | 内容 | 新名称／任务 |
| --- | --- | --- |
| 1 | 猎户座三颗腰带星 | 先认三点排列，再扩展两肩与两脚 |
| 2 | 猎户两颗关键星 | 参宿四、参宿七；将名字与骨架位置联系 |
| 3 | 大犬座 | 找天狼星，认识周围主体 |
| 4 | 小犬座 | 找南河三，记住它与猎户、大犬的关系 |
| 5 | 冬季大三角 | 参宿四、天狼星、南河三三点连通 |
| 6 | 金牛座 | 毕宿五、V 形区域、昴星团的位置 |
| 7 | 御夫座 | 五车二与主要五边形骨架 |
| 8 | 双子座 | 北河二、北河三与两列星的方向 |
| 9 | 冬季六边形 | 串起六颗亮星，回到起点 |
| 10 | 冬季区域复习 | 从猎户或任意已学亮星出发，定位其他目标 |

六边形采用本课固定顶点：**参宿七 → 天狼星 → 南河三 → 北河三 → 五车二 → 毕宿五 → 参宿七**。参宿四是冬季大三角顶点，不能混成这个六边形的顶点；双子座采用北河三这一顶点。[NASA 星群教学](https://science.nasa.gov/solar-system/skywatching/night-sky-network/connecting-the-dots-with-asterisms/)。

金牛座课程中，昴星团标为星团；毕宿五处于毕宿星团视线方向，但不要据此把它教成星团的物理成员。首轮不要求分别记住昴星团成员名称。[NASA：毕宿与昴星团](https://science.nasa.gov/solar-system/skywatching/night-sky-network/spot-the-young-stars-of-the-hyades-and-pleiades/)。

首轮新增 8 个星名：参宿四、参宿七、天狼星、南河三、毕宿五、五车二、北河二、北河三。

达标：不看名称与连线，指出 6 个星座的主要位置，完成三角形与六边形的关键星配对；从两个不同起点找目标。累计核心星座 9 个。

## 5. 第 3 阶段：从北斗扩展春季天空

| 顺序 | 内容 | 首次记忆任务 |
| --- | --- | --- |
| 1 | 复习北斗斗柄弧度 | 理解沿弧线继续寻找亮星 |
| 2 | 牧夫座 | 大角星；主要风筝形轮廓 |
| 3 | 室女座 | 角宿一；与大角星和北斗的导航联系 |
| 4 | 狮子座前部 | 镰刀／反问号形，轩辕十四 |
| 5 | 狮子座后部 | 五帝座一，前后两块结构连接 |
| 6 | 春季整体图 | 把北斗、牧夫、室女、狮子放到同一幅大图中 |
| 7 | 无提示导航 | 分别从北斗和狮子出发寻找已学目标 |

主路线：**北斗斗柄 → 大角星 → 角宿一**。这是有观测教学依据的定位方法。[Harvard–Smithsonian CfA：Spica](https://www.cfa.harvard.edu/news/understanding-spica)。

首轮新增：大角星、角宿一、轩辕十四、五帝座一。初学不必背室女座长串暗星，也不靠记一个孤立三角形替代认识邻区。

“春季大三角”有不同顶点选法。课程若加入，必须明写所用三颗星；本主线用大弧线避免在早期引入名称歧义。

达标：能独立复现大弧线，分清狮子前后结构；累计核心星座 12 个。

## 6. 第 4 阶段：从夏季大三角扩展到银河方向

| 顺序 | 内容 | 首次记忆任务 |
| --- | --- | --- |
| 1 | 夏季大三角三个顶点 | 织女一／织女星、天津四、河鼓二／牛郎星 |
| 2 | 天琴座 | 以织女星为锚点，识别附近小平行四边形 |
| 3 | 天鹅座 | 北十字骨架；天津四与十字的关系 |
| 4 | 天鹰座 | 牛郎星及其两侧较近的星点排列 |
| 5 | 大三角综合 | 分清一个星群跨越三个星座；双向练习星名与位置 |
| 6 | 天蝎座 | 心宿二、弯钩形主体与尾部 |
| 7 | 人马座 | 茶壶星群，建立与天蝎座的邻区关系 |
| 8 | 夏季整片天空 | 将大三角、天蝎、人马的相对区域串起来 |

首轮新增：织女一、天津四、河鼓二、心宿二。茶壶和蝎尾先记形状，骨架中的其他星名留到第二轮。

夏季大三角、冬季大三角和人马座茶壶均可作为识别辅助。[NASA 星群介绍](https://science.nasa.gov/solar-system/what-are-asterisms/)。这里选择天琴→天鹅→天鹰的课内顺序是教学编排，可按实际可见性调整。

达标：从大三角任意一个顶点找到其余两个，指出各自所属星座；辨认天蝎与人马主体。天蝎尾部在部分地点很低或不可见，真实观测题按条件裁剪，完整形状放模拟课。累计核心星座 17 个。

## 7. 第 5 阶段：用秋季大四边形连接星链

| 顺序 | 内容 | 首次记忆任务 |
| --- | --- | --- |
| 1 | 飞马大四边形 | 记较大的四角结构，理解它占据的角尺度 |
| 2 | 飞马座主体 | 辨认四边形与其外侧连线关系 |
| 3 | 仙女座 | 从四边形相连的一角追踪星链 |
| 4 | 英仙座 | 识别主要分叉结构，联系仙女、仙后和冬季邻区 |
| 5 | 南鱼座 | 找北落师门，建立秋季南方锚点 |
| 6 | 秋季整片天空 | 将四边形、星链、W 形和南方亮星放在同一幅图 |
| 7 | 秋冬桥接 | 仙女／英仙 → 御夫／金牛，把已学区域接起来 |

首轮必记新增星名：北落师门。四边形各角的名字留到结构熟悉后的第二遍。秋季大四边形包含三颗飞马座星与一颗仙女座星，不能把四角全算作飞马座成员。[香港太空馆：四季星空](https://hk.space.museum/sc/web/spm/resources/teachers-corner/starry-sky-of-the-four-seasons.html)。

达标：找到大四边形、追踪仙女星链、辨认英仙主要结构，并联系仙后与冬季区域。累计核心星座 **21 个**，首轮关键星名 **20 个**。

## 8. 第 6 阶段：把四季拼成一张连通的地图

此时暂停大量新增内容，练四类任务：

1. **多起点找星**：不是每次都从北斗或猎户开始，从任意熟悉目标出发。
2. **跨区连接**：英仙—御夫—金牛；双子与狮子之间的区域；室女与天蝎之间的区域；天鹰与飞马之间的区域。未学的中间星座可先以区域提示表示。
3. **时间变化**：同一地点改变夜间时刻或月份，重新寻找熟悉形状。
4. **由局部回到全图**：辨认局部后放大视野，指出它与其他锚点的关系；再反向从大图找到局部。

不要把相邻课程箭头一律解读成天空中的直线：只有经确认的星跳路线才显示方向延长线，其他箭头仅表示学习或邻区联系。

此阶段结束已具备日常认星主干。实际观测作为贯穿全程的独立任务，不要等背完 88 星座才开始抬头看天。

## 9. 第 7 阶段：回到熟悉区域，补第二批星名

每次加入 2–3 个名称，以原来熟悉的星图为背景。无需再同时学习全新图形。

| 顺序 | 名称组 | 怎么记 |
| --- | --- | --- |
| 1 | 北斗剩余名称 | 在已学天枢、天璇基础上加天玑、天权、玉衡、开阳、摇光 |
| 2 | 猎户腰带 | 参宿一、参宿二、参宿三；固定物理对象，不固定屏幕左右 |
| 3 | 秋季四边形 | 室宿一、室宿二、壁宿一、壁宿二；最后一个属于仙女座 |
| 4 | 仙女与英仙 | 奎宿九、天船三、大陵五，连到原有星链和分叉结构 |
| 5 | 已学星座其他骨架星 | 按常用程度加入，每座先补 1–3 颗，不设全体名称背诵门槛 |
| 6 | 南天主要星名 | 随后续南天课加入老人星、南门二、马腹一、十字架二、水委一 |

北斗按传统顺序复习为：**天枢 → 天璇 → 天玑 → 天权 → 玉衡 → 开阳 → 摇光**。这是命名与结构序列，不能替代北斗寻北时“天璇朝天枢”的具体方向。

此时再加入中英文名双向匹配，例如天狼星—Sirius、织女星—Vega；每次只开一种任务，不把中文回忆、英文拼写与拜耳编号混成一道必答题。

课程内容身份绑定物理对象 ID。现有数据中“天枢”存在不同文化语境下的别名碰撞；北斗课明确绑定 HIP:54061。用户层面显示本课星名与星图即可，不要求记 HIP 编号。

## 10. 第 8 阶段：依附已知骨架，补齐较暗邻区

按下表行顺序、行内箭头顺序学习；每个对象仍遵循“找到区域 → 认关键结构 → 选学主星名 → 无提示找回”。

| 路线 | 新增星座顺序 | 依托已学内容 | 新增数量 |
| --- | --- | --- | ---: |
| 北天补全 | 仙王 → 天龙 → 鹿豹 → 天猫 | 北极、仙后、大熊、御夫 | 4 |
| 春季补全 | 猎犬 → 后发 → 北冕 → 乌鸦 → 巨爵 → 长蛇 → 六分仪 → 小狮 | 北斗、大角、室女、狮子 | 8 |
| 夏季补全 | 武仙 → 蛇夫 → 巨蛇 → 天秤 → 盾牌 → 天箭 → 海豚 → 狐狸 → 南冕 | 织女、大角、天蝎、人马、天鹰 | 9 |
| 秋季补全 | 白羊 → 三角 → 双鱼 → 宝瓶 → 摩羯 → 小马 → 蝎虎 → 鲸鱼 | 飞马四边形、仙女、金牛、北落师门 | 8 |
| 冬季补全 | 巨蟹 → 麒麟 → 天兔 → 天鸽 → 波江 | 双子、狮子、猎户、大犬 | 5 |

新增 34 个，累计 **55 个**。这批不必在现实夜空中都达到相同识别难度：城市光害下较暗的目标，先达到“定位区域、说出邻座、在模拟图识别”的标准。长蛇、波江等跨度大的图形拆成若干局部课。

巨蛇座头部、尾部可以分两课，但 IAU 统计中仍是一个星座；本清单使用“巨蛇座（Ser）”。跨区域课程组织不表示这些星座在同一晚都处于理想位置。

## 11. 第 9 阶段：从南天锚点开始，拓展剩余 33 个星座

对北半球中纬度用户，采用南半球模拟场景；真实观测作为可选记录，不能要求用户在原地看到地平线下的对象。南半球用户则可以把本章锚点提前到入门阶段，使用适合当地的主线。

南天定向先认识南十字与半人马两颗亮星，再学习南天极附近方向，不能照搬北极星的方法。南十字可辅助定位南天极，是否拱极由观测纬度决定。[IAU OAE 南十字说明](https://www.astro4edu.org/resources/glossary/term/318/)。

| 顺序 | 路线 | 新增星座顺序 | 关键星名／辨析 |
| --- | --- | --- | --- |
| 1 | 南十字邻区 | 南十字 → 半人马 → 苍蝇 → 南三角 → 圆规 → 豺狼 → 天坛 → 矩尺 | 十字架二、南门二、马腹一；区别南十字与其他相似十字 |
| 2 | 老人星与南船 | 船底 → 船帆 → 船尾 → 罗盘 → 唧筒 → 飞鱼 → 绘架 | 老人星；船底、船帆、船尾的相对区域 |
| 3 | 波江南端邻区 | 凤凰 → 玉夫 → 天炉 → 时钟 → 雕具 → 网罟 → 剑鱼 → 水蛇 | 以已经学过的波江座南端和水委一为起点 |
| 4 | 南方鸟类与极区 | 天鹤 → 杜鹃 → 孔雀 → 印第安 → 显微镜 → 望远镜 → 天燕 → 蝘蜓 → 南极 → 山案 | 从已学南鱼附近扩展，再转向南天极周边 |

本章新增分别为 8、7、8、10 个，合计 33 个，累计 **88 个**。最后一组偏暗小的星座以区域关系为主要记忆线索，不要求每个都有鲜明拟物形状。

大、小麦哲伦云可作为附加方向背景，但其性质是星系；不额外算作星座。初学南门二时以肉眼目标学习，进阶再区分其多星系统和西方专名，不与比邻星混为同一颗可见亮点。

## 12. 第 10 阶段：全天综合、长期保持与实景迁移

建议按下列顺序综合：

1. **无名称的季节大图**：先指出锚点，再说出主要星座。
2. **无连线的背景星场**：找到关键骨架，避免依赖插图。
3. **随机局部图**：识别目标，并指出两个邻近星座。
4. **双向星名题**：看到名称能找位置，指向星点能回忆名称。
5. **路线题**：从两个不同已知目标寻找同一终点。
6. **变化时地**：改变观察地点、时间和视野，判断哪些目标可见。
7. **模拟与实景对照**：从手机图回到天空，用裸眼完成已学任务。
8. **跨日保持**：复习薄弱单元，定期用未见过的有效场景检查迁移。

初始达标规则建议：小单元在两种有效视图中无提示完成至少 4/5；一周后再测；季节整图从两个起点各找到 3–5 个目标。以上阈值用于试用校准，不是科学确定的普适分数线。

较暗小星座允许采用“定位天区＋说出邻座＋辨认图上关键结构”的标准。模拟达标与实地见过分别标记。用户请求提示后可以完成课程，但该次成功不记为无提示掌握。

## 13. 第 11 阶段：按兴趣扩展名称体系

这部分可在完成核心 21 星座后选修，不必等全部 88 星座，也不作为大众课程毕业门槛。

### A. 国际名称与科学编号

中文常用名 → 常见西方专名 → IAU 三字母星座缩写 → 拜耳编号（如 α Lyr）→ 常见弗兰斯蒂德编号 → 天区边界与赤经赤纬。

拜耳字母顺序不应被教成严格的亮度排名。早期课程只用星名与位置建立联系，不要求背距离、光谱和星表编号。

### B. 中国传统星官

熟悉的中文星名 → 所在星官（北斗、织女、河鼓、参、心等）→ 与现代星座叠加对照 → 三垣整体位置 → 二十八宿分组 → 四组之间的连通关系 → 更多星官。

这些是另一套文化分组，不能把“属于哪个现代星座”与“属于哪个星官”当成同一字段。三垣二十八宿专题另做经过来源审核的课程；本轮不让它打断现代星图入门主线。

## 14. 每个小单元的统一学习顺序

1. 看图与一条辨识线索。
2. 自己指出主要星点或轮廓。
3. 加入 1–3 个新名称。
4. 隐藏名称，进行星点→名称和名称→星点的双向练习。
5. 插入其他题目后，换一幅有效星图再找。
6. 连接至少一个已学邻区。
7. 跨日复习，再决定延长复习间隔。

建议每次 5–10 分钟、一个小单元。可采用“复习约 2 分钟＋学习约 4 分钟＋无提示练习约 2 分钟”的起始节奏；内容量和时间由用户表现调整。不要规定一天必过一章，也不要因某晚天气或光害而判学习失败。

“先学形，再学名”发生在每个单元内部；并不是先记完 88 星座才开始记星名。第一遍每个区域学少量关键星，第二遍再补充骨架中的其他名称。

## 15. 当季进入方式

默认完整顺序用于课程编排。实际观测允许在读图基础和合适的方向锚点练习后，从当地当前可见章节进入：

| 用户当前适合观测的章节 | 当季优先顺序（北半球晚间参考） |
| --- | --- |
| 冬季章节 | 猎户 → 大犬／小犬 → 金牛 → 御夫 → 双子 |
| 春季章节 | 北斗 → 牧夫 → 室女 → 狮子 |
| 夏季章节 | 夏季大三角 → 天琴／天鹅／天鹰 → 天蝎 → 人马 |
| 秋季章节 | 飞马四边形 → 仙女 → 英仙 → 南鱼 |

同一个星座可以跨多个季节或在不同夜间时段看见。系统最终用地点、时间、太阳高度、目标高度和课程关键星可见性选择有效内容，季节名称仅作为目录标签。可以参考[香港太空馆四季星图](https://hk.space.museum/sc/web/spm/resources/stars-maps-and-moon-map.html)，但该馆星图的观测条件不应直接套用所有地区。

## 16. 如何放入免登录产品

课程目录展示“读图入门、北方定向、四季主线、星名巩固、邻区补全、南天拓展、全天挑战”，每章都有具体目标和可见条件。普通用户完成四季主线即可获得阶段完成状态；继续拓展全天课程由用户选择。

免登录的本地记录按对象和能力保存，课程先后用软性推荐，不锁死用户想学的内容。每次访问显示“下一课”和“今日复习”；已学过的内容可通过诊断题跳过，失败则推荐补课。第一遍形状熟练与星名熟练分开显示，禁止用“点亮了一个星座”暗示其中全部星名都掌握。

每题提示曝光、别名与评分继续遵循主实施方案；不新增账号、上传记录或后台推送依赖。此文只规定教学顺序，不实现教学功能。
