# 恒星演示的外观依据与实现范围

2026-09-21。入口：`/demos/stellar-evolution`。

## 参考与设计选择

| 阶段 | 外观调整 | 观测或科学可视化依据 |
| --- | --- | --- |
| 分子云、原恒星 | 非均匀尘埃丝与团块、赤道尘埃消光、盘面、沿盘轴的双极外流 | [NASA / Webb：L1527](https://science.nasa.gov/missions/webb/nasas-webb-catches-fiery-hourglass-as-new-star-forms/) |
| 主序、白矮星、中子星 | 暖白至蓝白的温度色调；致密遗迹表面较平滑；脉冲星倾斜束和磁场示意 | [NASA：恒星类型](https://science.nasa.gov/universe/stars/types/) |
| 红巨星 | 橙色光球、大尺度对流胞，保持整体近球形 | [ESO：R Doradus 的 ALMA 动态观测](https://www.eso.org/public/news/eso2412/) |
| 行星状星云 | 不规则椭球气体壳、边缘增亮、不同颜色的内外气体区 | [NASA SVS：环状星云三维可视化](https://svs.gsfc.nasa.gov/31045) |
| 超新星 | 爆发闪光衰减后显示气体壳与细丝，不周期闪烁 | [NASA / Webb：仙后座 A](https://science.nasa.gov/missions/webb/nasas-webb-stuns-with-new-high-definition-look-at-exploded-star/) |
| 黑洞 | 黑色阴影、吸积盘温度渐变、亮度不对称、远侧盘面成像弧 | [NASA：黑洞扭曲的世界](https://www.nasa.gov/universe/nasa-visualization-shows-a-black-holes-warped-world/) |

这些参考不是统一的肉眼可见色照片。ALMA、Webb 的观测波段和映射色彩不能直接等同于可见光。星云颜色用于区分气体区域，光球颜色按温度趋势示意。页面为每个阶段提供双语说明与来源链接。

## 显示近似

- 恒星半径沿用原有 `R ** 0.21` 压缩方式；太阳参考圈保持同一尺度。
- 光球采用三维程序噪声表现对流颗粒，并使用临边昏暗；纹理尺度和时间均经过增强。这不是辐射流体模拟。
- 星云以两层不规则壳和细粒子补充细节；没有进行体积辐射输运。不同星云可以具有更复杂的双极、多极等形态。
- 原恒星的盘内缘在光球之外；尘埃消光在赤道较强，极区较弱。
- 黑洞采用非旋转 Schwarzschild 时空、远处观测者、理想无限薄且不透明的吸积盘（内缘 3 个视界半径）。CPU 以 RK4 预计算 `u'' = 1.5u² - u` 的光线路径，GPU 按 `φ + nπ` 求前三次盘面交点，并按先后遮挡；上下弧和窄环由交点产生，不再单独绘制或镜像交叉淡化。阴影标度使用临界冲量参数 `sqrt(27)/2`，全图尺度已压缩，不能据此测量。未模拟 Kerr 自转、盘厚度、背景星场透镜、光行时延迟或完整辐射输运；颜色、亮度和气体纹理仍为教学示意。缩放对应远处观测图像的放大，并非靠近黑洞的自由落体。
- 超新星的闪光与多年遗迹演化压缩成一段动画；脉冲星的磁力线是教学标记，辐射束不是实体光锥。
- 超新星抛射从一开始就允许方向差异、团块和低密度缺口，不采用“先完全均匀、很久后才不规则”的假设。[NuSTAR 对仙后座 A 的观测](https://www.nasa.gov/missions/nustar/nasas-nustar-untangles-mystery-of-how-stars-explode/)支持爆发本身存在不对称。显示的温度指早期冲击区，十万年指遗迹时标，不是光学爆发持续时间。
- 动画无外部图片下载依赖，没有新增运行时依赖；粒子与材质随场景销毁。

## 验证范围

### 黑洞穿过盘面时的连续成像

依据：[NASA SVS 360° 连续视角动画](https://svs.gsfc.nasa.gov/13326/)；[Bruneton 2020，式 (8) 与 §3.3.3](https://ebruneton.github.io/black_hole_shader/paper.pdf)。参考预计算光线与盘面交点的思路，本项目使用直接的二维 `u(b,φ)` 表，并非复现论文的完整波束追踪实现。

先前版本在 ±2° 内混合两幅固定的上下镜像，虽然像素颜色连续，但弧线轮廓仍在原位淡入淡出，导致生硬的翻转感。新模型随着有符号倾角改变同一光线与盘面的交点，近侧交点在接近侧视时移出有限的盘外缘，远侧像连续变形。对于此上下对称的理想模型，严格侧视的透镜像关于盘面对称；直接盘面的投影面积趋于零。有限厚度、有吸收的真实盘可能仍有窄带和自遮挡，不能把理想模型的侧视图当成所有黑洞的外观。

表为 1024×768、RGBA8 中的 16 位逆半径，光子捕获临界值附近非均匀加密；每像素采样四条相邻光线，有限分辨率只能解析部分高阶像。CPU 数组复用，GPU 纹理随材质释放。测试覆盖测地线守恒量、独立径向积分对照、捕获/逃逸和纹理释放；浏览器回归页 `/tests/browser/black-hole.html?transition` 提供慢速跨盘面运动，并检查透镜像轮廓移动，而不只比较 ±0.001° 的两帧。

回归覆盖阶段数据、颜色与尺寸顺序、时间轴、快速连续切换、闪光衰减、特效清理、光束锥尖位置、标签位置、双语键以及场景生命周期。浏览器检查覆盖九阶段模型及桌面、窄屏布局；生产构建验证 TypeScript 与资源打包。程序着色器还需实际 WebGL 渲染检查，单元测试不能代替 GPU 编译。

## 蟹状星云独立案例（已接入）

用户提供的 [NASA 三维资源](https://science.nasa.gov/3d-resources/crab-nebula/)提供约 2.11 MB 的 GLB；页面说明该模型以 Chandra X 射线结构为依据，包含中央脉冲星附近的环状结构与双向喷流。它不能直接替代整个外层气体壳。

[NASA 多波段可视化说明](https://science.nasa.gov/missions/hubble/nasas-great-observatories-help-astronomers-build-a-3d-visualization-of-an-exploded-star/)区分内部 X 射线结构、同步辐射弥散云和外层可见光丝状结构，并明确这是观测指导下的三维近似。蟹状星云是脉冲星持续供能的特殊案例，不把“超新星→蟹状星云→中子星”画成先后必经路径。

独立页面 `/demos/supernova-remnant` 已加入互动演示目录；恒星演化的超新星与中子星说明卡提供入口。NASA GLB 和 Draco WASM 解码器本地托管，无外部 CDN 依赖。保留原始几何，统一尺寸与中心，并替换为蓝色半透明材质；原文件不修改。原作者署名和来源见 `frontend/public/models/crab-nebula/README.md`。

外层细丝和弥散云是本项目程序化教学重建，并非 NASA 模型的一部分，也未拟合逐个真实位置。提供合成、可见光、红外、X 射线结构预设和三个独立图层开关；预设仅筛选对应结构，不模拟仪器响应或生成真实波段图像。自动环绕移动相机，不表示星云整体旋转。内部模型异步加载失败时明确提示并允许重试，其余图层仍能使用。

新增测试覆盖波段/图层状态、异步加载后保持图层可见性、失败重试、防止离开页面后附加模型、全景恢复及中英文文案。与恒星演化、注册表合计 122 项测试通过；生产构建通过。实际 WebGL 预览验证 NASA 模型、红外与 X 射线结构、内部放大、环绕和 1440×960 / 390×844 布局。
